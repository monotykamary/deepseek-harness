# 使用 Web UI

[English](index.md) | 中文

请先按照[根目录 README](../../../README.zh.md#run) 中的说明启动 Web UI；命令会打印其访问地址。本指南从服务器已经运行的状态开始。`dsh` 进程会把启动时所在的目录作为默认文件系统位置；全新的 Web UI 则不会选中任何工作区，你需要添加一个工作区。

## 配置模型

打开**设置 → 模型**，输入 [DeepSeek API 密钥](https://platform.deepseek.com/)并保存。模型路由会立即可用，不需要重启服务器。

[模型配置指南](./providers.zh.md)介绍其他提供方和自定义 OpenAI 兼容端点。

## 选择工作区

点击**选择工作区**，添加启动 `dsh` 时所在的项目目录，然后选中它。选中工作区前，会话输入框不可用。

## 查找或新建会话

展开的侧边栏会在**所有工作区**上方持续显示**搜索**。搜索会筛选 Session 标题、Workspace 名称和路径以及已持久化的消息文本；Session 卡片显示 Workspace、实时状态、标题、agent preset 与相对时间。使用「所有工作区」旁的**视图选项**可以切换分组或排序。

在 macOS 上按 `Cmd+K`，在其他平台上按 `Ctrl+K`，即可打开命令面板。输入会话标题、工作区名称或路径，也可以输入此前用户消息或 assistant 消息中的文字，然后选择匹配的会话。

选择**在工作区中新建会话……**即可指定工作区。用方向键高亮目标，按 `Tab` 接受选择但不创建任何内容，再按 `Enter` 创建或复用该工作区的空白会话。

## 运行任务

启动一个会话并发送：

> Summarize this repository and identify its main packages.

Agent（智能体）可以读取和编辑工作区文件、运行命令、委派工作并维护计划。如果根据当前权限策略，某项操作需要审批，Web UI 会先询问你。

## 使用交互式终端

打开一个 Session，然后使用 Session 标题栏中的**切换底部面板**，在对话下方显示可调整大小的终端。关闭该面板只会隐藏它，不会结束 shell；再次打开时会回到同一个终端标签。使用**新建终端**创建另一个持久 shell，确实要结束进程时再使用**终止终端**。

打开右侧面板并选择**终端**，即可在对话旁运行一个独立终端。在紧凑屏幕上，右侧 Workbench 会移入 Sheet，而底部终端仍附加在对话下方。

在任一位置使用**终端设置**，可选择主题、字体或自定义字体系列、字号、行高、连字、彩色表情符号和光标闪烁。这些外观选择同时应用于两个位置，并保存在当前浏览器配置中。
