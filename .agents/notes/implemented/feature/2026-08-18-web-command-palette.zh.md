# Agent Note: Web 命令面板的会话发现与工作区定向创建

Status: implemented

[English](2026-08-18-web-command-palette.md) | 中文

## 问题

Web UI 只在展开的侧栏中提供会话导航与内容搜索，而新会话会继承一个隐式工作区。键盘用户若要查找旧会话或选择特定工作区，必须经过侧栏状态；侧栏收起或处于移动端时，这条路径会更长。

命令启动器还必须与 composer 的斜杠命令含义分离。斜杠命令面向单个会话的、不经 agent 的 Host 命令目录；全局启动器导航应用根状态，并且在没有选中会话时也必须可用。

## 决策

`@monotykamary/dsh-client-ui-command-palette` 在布局所拥有的 `shell.overlay` 列表 slot 中注册一个根作用域条目。组件从标准运行时 share 接收 `useSessions` 与 `useWorkspaces`，注入工厂则把根服务收窄为打开、搜索与连接工作区的回调。查询、高亮、已接受工作区、进行中状态与错误都保留为组件局部状态，因为没有其他条目消费它们，关闭对话框即结束其生命周期。

Apple 平台上的 `Cmd+K` 与其他平台上的 `Ctrl+K` 会切换一个挂载到 `<body>` 末尾的模态对话框；该对话框在自身生命周期内让 `#root` 保持 inert，并在关闭时恢复此前的 inert 状态与焦点。根视图包含上下文相关与显式的新会话操作，以及十二个最近使用的可见根会话。搜索会按元数据字段的完全匹配、前缀匹配与包含匹配排序；至少两个字符的查询会在 250 毫秒后启动既有的、可取消的 `session.search` 请求，并把 Host 排序的摘要合并到同一份有界列表中。已归档会话、空白会话与 subagent 来源会话继续排除在外，使结果服从导航所有权，而不暴露隐藏的实现会话。

**在工作区中新建会话……** 会进入仅含工作区的视图。方向键移动虚拟高亮。`Tab` 接受一个工作区并显示已接受选择，但不产生副作用；只有 `Enter` 会提交 `connectWorkspace()`，随后调用 `sessions.open()`。这种分离使补全可逆，也防止常规焦点键创建会话。搜索与创建失败保留在对话框中，同时不会隐藏仍可用的元数据结果。

紧凑面板几何与 `--dsw-specific-command-palette*` 语义角色改编自 T3 Code 修订版 `a4cc1367b03ee0c1dc2b50fceac81ef5e63212e2`。实现保留 dsh 的 CSS Modules、token 所有权、Cordis 组合方式与 React 18 技术栈，不引入 T3 的 Tailwind、Base UI、Effect atoms 或单体命令组件。即使改编不构成实质复制，`scripts/gen-third-party-notices.ts` 也会输出已钉住的上游修订版、版权与完整 MIT 许可文本。

包测试以 100% 单文件覆盖率钉住纯排序与可见性、键盘和指针交互、取消竞态、创建失败、slot 声明到达、HMR dispose（资源释放）以及明暗 token 所有权。无密钥浏览器场景会启动已交付的 Web profile，搜索持久化消息内容并打开其会话，还会在确认新建会话前用 `Tab` 补全真实工作区。

## 考虑过的替代方案

**扩展 `ui-commands`。** 该包拥有 composer 中会话作用域的斜杠命令发现与执行。把全局导航交给它会合并两种命令含义，迫使无会话启动器依赖当前会话，并使覆盖层所有权变得含糊。

**复制 T3 Code 的命令组件与依赖栈。** 源组件在一个文件中混合项目克隆、文件浏览、主题操作、提供方状态与导航，并依赖 React 19 时代的应用依赖。直接复制会绕过 dsh 的 slot、本地化、token 与对象层规则；改编其交互与 token 角色，可以保留有价值的决策而不引入无关架构。

**在 `Tab` 接受工作区时创建会话。** 这样少按一个键，但会让焦点移动具有破坏性，也不给用户可见的确认点。因此 `Tab` 只补全，`Enter` 才提交。

**只保留侧栏搜索。** 既有侧栏搜索仍适合原位浏览，但无法从全局调用，也无法组合新会话定向。命令面板复用同一 Host 搜索操作，不改变侧栏所有权。

## 后果

Web UI 的任何状态都可使用会话发现与显式工作区定向，且无需改变 agent loop（智能体循环）、会话格式或模型可见上下文。新增客户端 bundle 与一个全局按键监听器都位于根作用域，并随插件 fiber 撤销；挂载到 `<body>` 末尾的 portal 使用仓库唯一的覆盖层层级。

首版操作清单与快捷键固定。可配置快捷键系统或第三方启动器操作需要由单独的客户端注册表拥有，不能在本包中推测性扩宽。元数据排序与远程内容搜索刻意保持简单且有界；更广泛的模糊排序或事件深链接属于独立行为变更。
