# @monotykamary/dsh-client-ui-command-palette

[English](README.md) | 中文

全局 Web 命令面板注册到布局所拥有的 `shell.overlay` 列表 slot。macOS 上的 `Cmd+K` 与其他平台上的 `Ctrl+K` 会在全部应用栏位之上切换一个挂载到 `<body>` 末尾的对话框；面板打开期间会让 `#root` 保持 inert，并把键盘焦点保留在搜索输入框中；关闭时则恢复此前的 inert 状态与焦点。

根视图显示“新会话”操作与最多十二个最近使用的可见根会话。非空查询会立即按会话标题、工作区标题与路径的完全匹配、前缀匹配和包含匹配排序。至少两个字符的查询还会在 250 毫秒后发出既有的、可取消的 `session.search` 请求，并把 Host 排序的消息摘要合并到有界的会话列表中。已归档会话、空白会话与 subagent 来源会话保持隐藏。内容请求失败时仍保留元数据匹配，Host 结果上限决定是否显示缩小查询范围的提示。

**在工作区中新建会话……** 会打开仅含工作区的视图。方向键移动虚拟高亮，`Tab` 接受高亮工作区但不创建任何内容，`Enter` 则创建或复用该工作区的空白会话并打开。工作区查询为空时按 `Backspace` 返回根视图；按 `Escape` 关闭对话框。未指定工作区的新会话沿用运行时的“当前工作区优先、最近工作区次之”策略；没有工作区时进入既有的新会话视图。

紧凑面板几何、分组结果层级、键盘提示页脚以及完全匹配／前缀匹配／包含匹配排序改编自 [T3 Code](https://github.com/pingdotgg/t3code) 的修订版 `a4cc1367b03ee0c1dc2b50fceac81ef5e63212e2`。T3 Code 采用 MIT 许可证，Copyright (c) 2026 T3 Tools Inc.；仓库生成的第三方声明保留完整许可文本。

`/client` 入口只导出 Cordis 插件主体、注入与组件约定类型以及本地化键类型。组件与投影辅助函数保持包内私有。

## Model Experience

无；命令面板只选择或创建浏览器会话，不会有任何内容进入模型请求。

#### KV Cache effect

无；本包既不组装也不发送提供方请求。

## Known Limitations and Deferred Work

- **快捷键与操作清单固定**——可配置快捷键和第三方命令面板操作需要由客户端命令注册表统一拥有，本包才可开放这些功能。
- **工作区行用于创建会话**——首版命令面板没有项目落地页，因此选择工作区明确表示新建会话，而不是导航到既有会话。
